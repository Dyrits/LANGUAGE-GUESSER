# Language Guesser

A command-line tool that guesses the language of a given text, built while following the Udemy course "The Web Developer Bootcamp".

## About The Project

This small Node.js program takes a text as argument and prints the most probable language, using franc for detection and langs to resolve language names.

## Built With

- Node.js
- franc / franc-min
- langs

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

```bash
npm install
```

### Usage

```bash
node index.js "Your text here"
```
